# 프로젝트 계획서
**Plan ID**: PLAN-000001
**생성일**: 2026-09-16

## 프로젝트 아이디어
노인 친화 UI로 짧은 위령기도(위령기도 2)를 크게 읽고, 고인 이름을 괄호 자리에 자동 채워 바칠 수 있는 웹 사이트.

## 목적
- 기존 굿뉴스 기도문 화면보다 글자를 크게·단순하게 볼 수 있게 한다.
- `( )` / `(연령)` 자리에 고인 이름을 한 번 입력하면 본문 전체에 반영한다.
- 조사(을/를, 이/가, 은/는 등)를 이름 끝소리에 맞게 자동으로 맞춘다.
- 상황별 맺음 기도(사망~장례 / 탈상 / 기일 / 설·한가위)를 쉽게 고른다.
- 설치 없이 스마트폰·태블릿·PC 브라우저에서 바로 사용한다.

## 핵심 기능

### 1. 짧은 위령기도 본문 표시
- 참고: [가톨릭 굿뉴스 위령기도 2(짧은 위령 기도)](https://app.catholic.or.kr/web/prayer/?flag=7&ingId=69)
- 구성 순서:
  1. 안내 문구(짧은 위령 기도를 바칠 때 이 양식을 따름)
  2. 시작 성호경
  3. 본기도(고인 이름 자리 다수)
  4. 시편 129(130)
  5. 「주님 …에게 영원한 안식을…」응답
  6. 시편 50(51), 3–21
  7. 안식·빛 응답 + 「주님 저희의 기도를…」교환
  8. 상황별 맺음 기도 1~4 중 선택 표시
  9. 주님의 기도·성모송 안내
  10. 마치는 기도(연령 자리)
- 역할 표시(╋ / ○ / ● / ◎)를 색·굵기로 구분하되, 장식은 최소로 유지한다.
- 기도문은 앱 내 정적 데이터로 보유한다(외부 사이트 실시간 스크래핑 없음).

### 2. 고인 이름 입력·본문 치환
- 화면 상단(또는 고정 바)에 「고인 이름」입력칸을 둔다.
- 입력 즉시 본문의 `( )`, `(연령)`, `(망자)` 등 이름 자리를 같은 이름으로 채운다.
- 조사 자동 처리:
  - `를(을)` → 받침 있으면 `을`, 없으면 `를`
  - `가(이)` → 받침 있으면 `이`, 없으면 `가`
  - `는(은)` → 받침 있으면 `은`, 없으면 `는`
  - `에게` 등 불변 조사는 그대로 유지
- 이름이 비어 있으면 빈칸을 시각적으로 강조(밑줄/박스)해 「여기 이름을 넣는다」는 느낌을 유지한다.
- 여러 명(형제·자매 등)은 v1에서 쉼표로 이어 쓴 한 줄 입력을 허용하고, 조사는 마지막 글자 기준으로 적용한다.

### 3. 글자 확대·축소 (+ / −)
- 화면 어디에서도 닿기 쉬운 고정 컨트롤: `A−` / `A+` (또는 `−` / `+`).
- 본문 기본 글자 크기: 약 22px, 최소 16px ~ 최대 40px 범위에서 단계 조절.
- 선택한 크기는 `localStorage`에 저장해 다음 방문에도 유지.
- 브라우저 자체 확대와 충돌하지 않도록, 앱 내 글자 크기만 바꾼다(레이아웃 깨짐 최소화).

### 4. 상황별 맺음 기도 선택
- 큰 버튼/탭 4개:
  1. 사망일~장례일
  2. 장례 후~탈상일
  3. 기일
  4. 설·한가위
- 선택 시에만 해당 기도문을 본문에 보여 주고, 나머지는 접거나 숨긴다.
- 기본값: 「기일」(가장 자주 쓰는 경우로 가정).

### 5. 노인 친화 UI·접근성
- 높은 대비(어두운 글자 / 밝은 배경), 넉넉한 줄간격·문단 간격.
- 터치 영역 최소 44px 이상(확대 버튼·이름 입력·상황 선택).
- 불필요한 메뉴·광고·링크 없음. 첫 화면 = 이름 입력 + 기도문.
- 가로 스크롤 없이 한 열 읽기. 모바일 우선, 태블릿·PC에서도 읽기 폭 제한(약 40~50자).
- 선택: 「화면 켜짐 유지」(Wake Lock)로 기도 중 화면이 꺼지지 않게 한다(지원 브라우저만).

## 기술 스택
- 프론트엔드: Vite + React + TypeScript
- 스타일: 순수 CSS(변수 기반). UI 라이브러리 최소화
- 상태/저장: React state + `localStorage`(글자 크기, 최근 이름, 상황 선택)
- 배포: 정적 호스팅(Vercel 또는 GitHub Pages). 백엔드·DB 없음
- 패키지 위치: 저장소 루트에 웹 앱(`package.json` 등). 문서 허브는 `docs/` 유지

## 사용자 시나리오
1. 가족이 사이트를 연다.
2. 상단에서 글자를 `+`로 키운다.
3. 「고인 이름」에 예: `김영희`를 넣는다. 본문 `( )를(을)` → `김영희를` 등으로 바뀐다.
4. 「기일」을 고른다(또는 이미 선택됨).
5. 화면을 스크롤하며 짧은 위령기도를 바친다.
6. 다음에 다시 열면 글자 크기·이름이 그대로 남아 있다.

## 제약사항/요구사항
- v1 범위는 **짧은 위령기도(위령기도 2)만**. 긴 위령기도·다른 기도문은 이후 plan.
- 기도문 출처는 가톨릭 기도서/굿뉴스 공개 기도문. 상업 재판매·원문 무단 대량 복제 목적이 아니며, 개인·가정·본당 기도 보조용으로 사용한다. 사이트에 출처 링크를 작게 표기한다.
- 로그인·계정·서버 저장 없음. 개인정보(이름)는 기기 로컬에만 둔다.
- 오프라인: v1은 온라인 접속 기준. PWA/오프라인 캐시는 후속 과제.
- 한국어 UI만(영문 불필요).

## 화면 구성(초안)
1. **고정 상단바**: 제목 「짧은 위령기도」 · 이름 입력 · A− / A+
2. **본문**: 기도문(치환된 이름 포함)
3. **중간**: 상황 선택 버튼 4개 + 선택 맺음 기도
4. **하단**: 주님의 기도·성모송 안내 + 마침 기도 · 출처 링크

## 구현 우선순위
1. 기도문 데이터 구조화(플레이스홀더·조사 규칙)
2. 이름 치환 + 조사 자동 처리
3. 글자 크기 조절 + 저장
4. 상황별 맺음 기도 전환
5. 모바일 가독성·접근성 다듬기
6. 정적 배포

## 성공 기준
- 이름 입력 한 번으로 본문 모든 해당 칸이 채워진다.
- `+`/`−`로 글자가 눈에 띄게 커지고, 새로고침 후에도 유지된다.
- 70대 사용자가 설명 없이 이름 넣고 읽을 수 있을 정도로 버튼·글자가 크다.
- 스마트폰 세로 모드에서 가로 스크롤 없이 끝까지 읽을 수 있다.
